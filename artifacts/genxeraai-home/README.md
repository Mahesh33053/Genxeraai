# GenXEraAI Frontend Application

Official client portal for **GenXEraAI** with complete SEO, 12 dynamic internship tracks, breadcrumb navigation, and Vercel hosting readiness.

See the root [README.md](../../README.md) for full project architecture, deployment instructions, and robot testing details.

## Quick Start

```bash
pnpm install
pnpm run dev
```

## Production Build

```bash
pnpm run build
```
Build output is saved to `dist/public`.
